to run the simple version
1. adjust credentials hardcoded in index.js
2. run npm install
3. start Neo4j
4. run "node index.js"
5.inspect GraphQL API using Apollo Studio in browser


to run the full version:
1. adjust credentials in src/config/config.ts
2. run "npm install"
2. start Neo4j
2. start Kafka in docker container/locally
3. ts-node src/main.ts
4. inspect GraphQL API using Apollo Studio in browser
